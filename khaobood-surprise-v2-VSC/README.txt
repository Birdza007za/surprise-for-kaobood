# ข้าวบูด Surprise — VS Code

เปิด `index.html` ด้วย Live Server

รูปที่ใส่ให้แล้ว:
- assets/go-button.png = ปุ่มจากรูปที่นายส่ง
- assets/sad-momonga.png = รูปแรก (ไม่คิดถึง)
- assets/happy-momonga.png = รูปที่สอง (คิดถึงง)

ถ้าจะเปลี่ยนรูปในอนาคต ให้ใช้ชื่อไฟล์เดิม หรือแก้ตัวแปรด้านบนของ script.js

จุดที่แก้จากเวอร์ชันก่อน:
- ปุ่ม "ไปต่อ" สร้างใหม่แบบ DOM และผูก click โดยตรง จึงไม่ติดปัญหาไปหน้า 4 ไม่ได้
- หน้า 2 และหน้า 3 เลือกคำตอบแล้วอีกปุ่มจะหาย
- หน้า 4 พิมพ์ข้อความทีละตัว
- หน้า 5 ซองเปิดและมีเอฟเฟกต์ดอกไม้
